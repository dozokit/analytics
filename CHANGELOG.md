# Changelog

How to update your copy: [dozokit.com/analytics/guide#updating](https://dozokit.com/analytics/guide#updating).

## 1.3.1 – 2026-10-27

- On a phone, the site picker, the online count and Settings share one row, and the section tabs scroll sideways instead of being cut off.

## 1.3.0 – 2026-10-26

- Overview → Goals shows under each goal where it fires: its top pages, and on All sites the site too.

## 1.2.2 – 2026-10-26

- The update button installs only the latest release, and only once it checks the release is signed with Dozokit's release key, which lives on one computer. A release that isn't signed with it is refused and nothing changes. Before, it took the newest files on GitHub as they were.
- Settings → Updates has Replace it, for copies that added the update button before 1.2.2: press it once to get the signed one.

## 1.2.1 – 2026-10-26

- Settings → Updates adds the update button to your GitHub copy in one click. Cloudflare's Deploy button leaves it out, so copies made with the button need this once.

## 1.2.0 – 2026-10-25

- Update with a click: on GitHub, Actions → Update Dozokit Analytics → Run workflow.
- Change your password in Settings. Editing `PASSWORD` in Cloudflare resets it if you forget it.

## 1.1.0 – 2026-10-25

- The dashboard says when a newer version is out, with a link to the update steps.

## 1.0.0 – 2026-10-25

- First public release.
